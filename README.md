# 聲調譜 TONESCORE

台湾華語（繁体字・注音）のリスニングと発音を鍛えるための、ブラウザだけで動く練習アプリ。
**声調を「規則」ではなく「旋律」として掴む**ことに絞って作っている。

**公開ページ:** https://aratama-ship-it.github.io/tonescore/

## できること

### 練習（声調譜）

1. **旋律で掴む** — そのフレーズの声調をサイン波の旋律として鳴らす。意味の前に形を耳で捕まえる。
2. **中文を聞く** — ブラウザの音声合成（台湾の声があればそれ）で読み上げ。
3. **押している間、話す** — 指を離した瞬間、自分の声のピッチ曲線が規範カーブに重なって描かれる。
4. 音節ごとに「上がりが足りません **+0.9半音**」のように具体的な数値で指摘する。

- 注音は台湾の教科書どおり**漢字の右に縦組み**で表示。
- **變調**（三声が続くと前が第二声になる）は、変調前の声調を点線で残して見せる。

### 耳だけモード

「中文だけ / 中文→日本語 / 中文→間→中文」の並び、速さ、間を決めて聞き流す。

### フレーズ集

- **現地で使う** — 店・移動・値段。捷運（MRT）・加值（チャージ）・外帶（持ち帰り）など台湾の語彙。
- **仕事・公演** — 天井の高さ、床の滑り、リハーサル時刻など、現場で本当に必要になる質問。
  ディアボロは台湾の語である **扯鈴**（大陸の「抖空竹」ではない）。
- **声調だけの素振り** — 意味を捨てて形だけ入れる。

## 読み方（ここが分かると全部分かる）

- **朱の線** = 規範カーブ。五度式（第一声=55／第二声=35／第三声=214／第四声=51）から描いた**理論値**。
  ブラウザは音声合成の出力波形を解析用に取り出せないため、**模範音声の実測ではない**。
- **青磁の線** = あなたの声。マイク入力から基本周波数（F0）を**実測**したもの。
- 縦軸は絶対的な高さではなく、**その収録の中央ピッチを0とした半音**。
  だから声の高さが違っても、声調の形だけを比べられる。
- 横軸は音節ごとに正規化している。ここで見ているのは声調の形で、リズムではない。

## 使い方

公開ページを開くだけ。マイクを使うため **HTTPS（または localhost）が必要**。

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」で全画面起動。
- 読み上げに台湾の声が出ない場合は、iOS の
  設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 中国語 から「台湾」の声を追加する。
- 耳だけモードは、画面ロック中に止まることがある（音声合成APIの制約）。

## 表現の確からしさについて

フレーズには確度のフラグを持たせている。台湾での自然さが未確認のものは
画面に「**未確認**」と表示される。確定した事実として扱わないこと。

## 開発

依存パッケージなし。ビルド不要。

```bash
node tests/check.mjs   # ロジック検証（データ整合・注音変換・変調・判定・区間分割）
```

配信物を変えたら `sw.js` の `VERSION` と `index.html` の `?v=` を揃えて上げる。
設計上の決定と未検証項目は `PROJECT_NOTES.md` に書いてある。
